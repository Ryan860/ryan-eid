Ryan Eid Portfolio Website

Files included:

- english-course.html: dedicated English / Work Ready Now course page
- styles.css: full professional responsive design
- script.js: language selector, scroll animations, tabs, filters, counters, active nav, back-to-top

Fast deployment:
1. Unzip this folder.
2. Drag the folder named ryan-portfolio-static into Netlify Drop.
3. Netlify will generate a public link.
4. Test the Download CV PDF button and the English Course page before presenting.
